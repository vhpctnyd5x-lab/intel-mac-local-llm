# Blender の「カーネル」

Blender 4.5 の3Dビューで `N` を押すと、横の欄に「カーネル」が出ます。
開いている場面について手元の AI に頼み、返ってきた Python 台本を確認して実行できます。

## 入れる

1. このフォルダで `bash tsutsumu.sh` を実行して `kernel_ai.zip` を作ります。Blender は起動しません。
2. 本人が `/Applications/Blender.app` を開き、**編集 > プリファレンス > アドオン** の右上メニューから **ディスクからインストール** を選び、この zip を指定します。
3. 「カーネル」を有効にします。アドオンの設定で **カーネルの場所** を確認します。既定は `~/LocalAI_mirror/kernel`。ここに `sanjigen.py` と `sanjigen.md` が必要です。正本は読み込むだけで変更しません。
4. 手元の llama-server を通常の方法で起動します。接続先は `http://127.0.0.1:8080/v1/chat/completions` 固定です。必要なら設定の **頭脳のモデル名** を変えます（既定 `local`）。

## 使う

1. 編集したい物体を選び、3Dビューの **N > カーネル** に「この椅子の脚を細くして」などを入力します。入力は1行、履歴は最新8件です。対象の物体名も書くと明確になります。
2. **考える** を押します。状態に「考え中… 何秒」と出ます。通信は別スレッド、待ちは最大600秒です。**やめる** で通信を打ち切れます。台本を勝手に実行することはありません。
3. 返ってきた台本はテキストデータ **kernel_台本** に入り、欄にも冒頭を表示します。**台本を表示** で既存のテキストエディター、またはタイムラインをテキストエディターに替えて開きます。別の領域を自分でテキストエディターに替えて選ぶこともできます。
4. 内容を見て **実行**。表示中のテキストを再検査するので、手で直した場合も検査されます。変更は **編集 > 元に戻す**（通常 `Cmd+Z`）で戻せます。グローバルの元に戻す設定が無効なら実行しません。
5. 失敗したら **直して** で、元の頼み・失敗した台本・エラー・現在の場面の要約を添えて1回だけ考え直します。途中の変更が残った場合は、先に元に戻してから直してください。さらに直したいときは新しい頼みとして **考える** を押します。

サーバーが停止中なら「カーネル（手元の頭脳）が起きていません」と表示します。
通信中に場面を読み替えた場合は中止します。別の場面へ移ったら新しく考えてください。

## 既存の場面・通信

- `sanjigen.py` の `_worker` は呼びません。全物体削除・自動下見・初期化なしで、`bpy`・`bmesh`・`Vector` だけを注入して公開の道具箱関数を `kit` として使います。
- 正本の `validate`（AST 検査）に追加検査を重ね、import は `kit` / `bpy` / `bmesh` / `mathutils` / `math` だけに限定します。物体削除や場面初期化、保存等は禁止です。`kit.export`・`kit.preview`・`kit.bake_texture` は提供しません。UV 展開・パーツ分離・形状編集は利用できます。
- 頭脳へ送るのは頼み、道具箱説明、最大60物体の要約（名前・種類・頂点／面数・位置・大きさ・材質・選択・UV）。選択中の物体を優先し、メッシュそのものや画像は送信しません。
- 通信は数値アドレス `127.0.0.1` だけです。環境変数の HTTP プロキシを使わず、HTTP リダイレクトも追いません。台本・場面を外部サービスへ送る機能はありません。
- 実行は本人の Blender 内の Python です。AST 検査は完全な隔離ではありません。台本の確認が前提です。**やめる** は生成通信用で、実行を始めた Python は中断できません。

## 試験（Codex は Blender を起動しない）

通常試験は偽のローカル HTTP サーバーを使用し、Blender を起動しません。

```sh
SEISEI_BLENDER=0 python3 blender_addon/test_addon.py
bash blender_addon/tsutsumu.sh
```

Blender を使う試験は Claude が砂箱の外で、明示的に次を実行します。

```sh
SEISEI_BLENDER=1 python3 blender_addon/test_addon.py
```

実機試験は初期場面からの登録・偽サーバー経由の生成・編集・UV・Undo・修正1回・解除を確認します。本人が開いている場面ではなく、`--background --factory-startup` の試験専用 Blender を使います。
本人の画面では、Nパネルの表示／経過秒／台本表示／中止／元に戻すを確認してください。

API の参照: [Blender 4.5 タイマー](https://docs.blender.org/api/4.5/bpy.app.timers.html)、[元に戻す API](https://docs.blender.org/api/4.5/bpy.ops.ed.html)。
